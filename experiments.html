MathML: mass-energy equivalence

Einstein's mass-energy equivalence, written in MathML:

E = m c 2

Why MathML took so long to be usable

MathML has been part of web standards since the late 1990s, but for most of that time developers couldn't count on it. Firefox and Safari supported it, but Chrome, the most widely used browser, did not. Chrome briefly shipped MathML in version 24 and then removed it, and it only came back when Chrome 109 added MathML Core in January 2023. Since Edge and Opera are built on Chromium, they gained support at the same time. Until then, sites had to rely on JavaScript libraries like MathJax or on images of equations.
