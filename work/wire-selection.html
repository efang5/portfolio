Wire Selection Model

Packet Micro, Santa Clara · June to September 2026

I built Cable Matcher, a tool that scores how similar any two cables are by comparing features pulled from their TDR curves. It combines those features into one score using weights learned from an engineer's real pairing decisions, turning past judgment into something repeatable and automatic.

Details here are kept general to protect Packet Micro's internal data.

My Role

As an intern, I built Cable Matcher's Python backend, including the feature extraction and the weight learning, and its React review tool, where pairs of curves are compared and labeled. I also added a sorting feature to a Streamlit app that reuses the same peak and trough logic.

Problem

Choosing the right wire for a probe was a manual engineering decision. It depended on an engineer's experience and took time on every job. It was time consuming to have an engineer check for every possible pairing in a set.

Approach

  1. Pull features from each curve. For every cable, I find the peaks and troughs in its TDR curve and turn them into a small set of numbers that describe its shape.
  2. Compare two cables feature by feature. For any pair, each feature gives its own measure of how close the two cables are.
  3. Learn how much each feature matters. Using pairs an engineer had already matched, I fit a weight for each feature so the combined score agrees with the engineer's decisions.
  4. Score every pairing. The weighted features add up to one similarity score, so every possible pair in a set can be ranked automatically.

The model is deliberately simple: a set of linear weights fit with SciPy's optimizer, not a neural network. That keeps it fast, easy to explain, and easy to check against what an engineer would have chosen.

Engineers review pairs in a React tool that overlays two cables' curves on one chart, and those labels feed back into the weights. Each trained version of the weights is saved, so a new version can be compared with older ones.

Result

Instead of an engineer checking every possible pairing in a set by hand, Cable Matcher scores all of them automatically, so the engineer starts from a ranked list. Because the weights come from real decisions, the scores follow the same judgment every time.

Tech used

  • Backend: Python, FastAPI, Uvicorn, Pydantic, aiosqlite
  • Modeling: SciPy (optimize.minimize, signal.find_peaks), NumPy, pandas, joblib, Matplotlib
  • Review tool: React, Vite, Recharts
  • Sorting add-on: Streamlit
